## Cómo ejecutar la app (Practica5/miapp1)

1. Entra al directorio del proyecto:

```bash
cd Practica5/miapp1
```

2. Instala dependencias:

```bash
npm install
```

3. Inicia la aplicación con Expo:

```bash
npx expo start
```

4. Abre la app en un emulador o en tu dispositivo con Expo Go, o usa las opciones de simulador (Android/iOS) desde la interfaz de Expo.

Notas:
- Si usas TypeScript, revisa la configuración en `tsconfig.json` (si existe) y sigue las indicaciones específicas del proyecto.
- Para problemas de linting: `npx expo lint`.
